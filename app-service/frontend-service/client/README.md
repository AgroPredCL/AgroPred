## Instalación

1. Instala node JS en https://nodejs.org/en
2. Estar en la ruta de la carpeta client y colocar
 ```bash
# Install dependencies
npm install
```
## Uso
Para iniciar el proyecto colocar en terminal: 
 ```bash
# Start project
npm run dev
```
